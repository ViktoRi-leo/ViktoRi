# Асимметричный заряд (Asymmetric)

Чередование заряда и разряда для десульфатации – растворения кристаллов сульфата свинца на пластинах.

<Callout type="info">
  Для работы необходим разрядный модуль (нагрузка – лампа или резистор). Без него разрядная фаза не работает.
</Callout>

## Как работает

Режим циклически чередует подачу тока заряда и разряда:

1. Подаётся ток заряда в течение периода заряда
2. Пауза (настройка «Пауза»)
3. Подаётся ток разряда в течение периода разряда
4. Пауза
5. Цикл повторяется

Периоды заряда, разряда и паузы задаются в секундах.

### Принцип десульфатации

При длительном хранении или глубоких разрядах на пластинах свинцового АКБ образуются крупные кристаллы сульфата свинца. Обычный заряд их не растворяет.

Чередование заряда и разряда разрушает кристаллическую структуру:
- Заряд – растворяет поверхность кристаллов
- Разряд – ослабляет связи в решётке
- Повтор – постепенно разрушает даже крупные кристаллы

## Завершение

Работа завершается только по истечении установленного времени (настройка «Время»). По напряжению и току режим не завершается, процент заряда на экране не считается.

Также работа остановится, если снять клемму с аккумулятора.

После завершения ViktoRi переходит в режим [Хранение](/docs/rezhimy/hranenie). Если количество циклов больше 1, режим повторяется с паузой между циклами (по умолчанию 60 минут, параметр `PBC`).

## Когда использовать

- АКБ с начальной стадией сульфатации
- Профилактика для свинцовых АКБ
- Восстановление ёмкости после длительного простоя
- Перед [методом Бранимира](/docs/rezhimy/zaryad-branimira) – для подготовки пластин

<Callout type="warning">
  Асимметричный заряд эффективен только для свинцовых АКБ. Для литиевых не применяется.
</Callout>

## Настройки

| Русский (LCD) | English | Транслит | Описание |
|--------------|---------|----------|----------|
| Напр. | Volt | Volt | Напряжение заряда (В) |
| Заряд | Charge | Zaryad | Ток заряда (А) |
| Разряд | Discharge | Razryad | Ток разряда (А) |
| Заряд сек | Charge sec | Zaryad sek | Длительность фазы заряда (1–255 сек) |
| Разряд сек | Disch. sec | Razryad sek | Длительность фазы разряда (1–255 сек) |
| Пауза сек | Pause sec | Pause sek | Пауза между фазами (1–255 сек) |
| Время | Time | Vremya | Общее время работы (1–255 часов) |
| Цикл | Cycle | Cycle | Количество циклов (1–5) |
