# Приложение ViktoRi

ViktoRi – настольное приложение для прошивки и настройки зарядного устройства. Всё нужное для сборки уже есть внутри: компилятор, библиотеки, PlatformIO, Python и AVRDUDE. Arduino IDE, ядра плат и библиотеки ставить не нужно. Можно установить приложение на чистую Windows и сразу прошить зарядное

<AppDownload />

## Возможности

1. Уведомления о выходе новых прошивок
2. Запись готовых HEX и BIN без компиляции
3. Поддержка прошивки зарядного ViktoRiESP32
4. Сборка собственных прошивок из локальной папки
5. Прошивка логгеров Loger ViktoRi, LogiViktori и ULoger
6. Выбор загрузчика при компиляции (Stock, Metro, Gyver, Old)
7. Удобная настройка и калибровка параметров зарядного устройства
8. Проверка доступного объёма памяти платы перед записью прошивки
9. Возможность ручного редактирования конфигурационных файлов зарядного устройства
10. Автоматическая диагностика ошибок компиляции и записи прошивки с указанием причин
11. Сборка прошивки с выбранными настройками и её запись в устройство по USB одним нажатием
12. Встроенная документация зарядного устройства со схемами, кодами завершения и справочной информацией
13. Загрузка актуальных прошивок напрямую с сервера с возможностью быстрого переключения между версиями

## Системные требования

| Система | Файл |
|---------|------|
| Windows 10 или 11, 64-бит | установщик `.exe` |
| macOS на Apple Silicon (M1 и новее) | образ `.dmg` |
| Linux x64 | `AppImage` или архив `.tar.xz` |

<Callout type="warning">
  Windows 7, 8 и 8.1 не поддерживаются
</Callout>

Интернет нужен, чтобы скачать версии прошивки и обновления. Скачанные версии остаются на компьютере, их можно собирать и прошивать без сети

## Драйвер USB

Драйверы USB приложение само не устанавливает. Большинство плат Arduino Nano сделаны на мосте CH340. Windows 10 и 11 обычно находят для него драйвер сами при первом подключении

Если после подключения платы порт не появился в окне подключения:

1. Проверьте кабель. Многие кабели, особенно от зарядок, умеют только питать устройство и не передают данные
2. Посмотрите в Диспетчере устройств, появляется ли новое устройство при подключении платы
3. Если устройство помечено как неизвестное, установите драйвер CH340 с сайта производителя чипа (WCH)

## Дополнение «Поддержка ESP»

Для зарядного на Arduino Nano / LGT, LogiViktori и ULoger установщика достаточно

Классическому Loger ViktoRi и ViktoRiESP32 нужен компилятор для ESP32. Он большой, поэтому скачивается отдельно, около 1 ГБ. Когда вы откроете эти разделы в первый раз, приложение предложит **«Скачать дополнение»**. Скачивается оно один раз. Если новой версии приложения понадобится обновлённое дополнение, приложение предложит скачать его снова

## Где хранятся данные

Настройки, скачанные прошивки, результаты сборок и история лежат в папке данных, отдельно от самого приложения:

| Система | Папка |
|---------|-------|
| Windows | `%APPDATA%\ViktoRi` |
| macOS | `~/Library/Application Support/ViktoRi` |
| Linux | `~/.config/ViktoRi` |

Ваши личные настройки зарядного лежат в `devices/viktori/settings/0_My_Setup.h` внутри этой папки

## Удаление в Windows

Удалите приложение как обычно, через «Параметры → Приложения». В конце деинсталлятор предложит:

**☐ Удалить настройки, скачанные прошивки, историю и кэш приложения**

По умолчанию галочка снята, и данные остаются: если установить приложение заново, всё будет на месте
