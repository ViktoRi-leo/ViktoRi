# Сборка логгера

Все логгеры ([Loger ViktoRi](/docs/logger/loger-viktori), [ULoger](/docs/logger/loger-uklon), [LogiViktori](/docs/logger/logi-viktori)) собираются из одних и тех же модулей. Набор компонентов одинаковый – разница только в прошивке.

Логгер собирается как «бутерброд» – модули устанавливаются друг на друга. Кастомная плата не нужна.

![Собранный логгер](/images/logger/LogerCompleted.webp)

## Что нужно

| Компонент | Описание |
|-----------|----------|
| Wemos D1 Mini (ESP8266) или ESP32 (Wemos D1 Mini32) | Основная плата. ESP32 поддерживает Telegram (в LogiViktori) |
| MicroSD shield | Шилд с разъёмом для карты памяти |
| MicroSD-карта | SDHC, Class 10, до 32 ГБ, FAT32 |
| RTC-модуль (опционально) | DS3231 рекомендован, DS1307 допустим. Хранит время при выключении питания |
| Шилд RTC + MicroSD (опционально) | WeMos D1 DS1307 – совмещает RTC (DS1307) и MicroSD на одной плате. Удобный вариант «два в одном» |

<Callout type="warning">
  На шилде WeMos D1 DS1307 нужно отпаять резистор и диод. Резистор – дублирует подтяжку I2C, диод – заряжает батарейку CR2032 (она не рассчитана на заряд).

  <div style={{ maxWidth: '200px' }}>
    ![Компонент для отпайки на WeMos D1 DS1307](/images/logger/ds1307.webp)
  </div>
</Callout>

<Callout type="info">
  RTC не обязателен, но желателен. Без него время синхронизируется через NTP (нужен интернет) или вручную через браузер. При отключении питания без RTC время сбрасывается.
</Callout>

<Callout type="info">
  В Loger ViktoRi SD-карта не обязательна – без неё данные отображаются в браузере, но не записываются. В ULoger и LogiViktori SD-карта обязательна.
</Callout>

## Подключение к зарядному устройству

Три провода от Arduino к ESP-модулю:

| Arduino | ESP | Назначение |
|---------|-----|------------|
| 5V | 5V | Питание |
| GND | GND | Земля |
| TX (D1) | RX | Данные |
| RX (D0) | TX | Управление (опционально, при включённом REMOTE_CONTROL) |

На плате 2.3.1 есть готовый 4-пиновый разъём – достаточно подключить кабель.

### Провод управления

Провод TX логера → RX (D0) зарядного нужен только для отправки команд
Прошивка логера должна поддерживать управление, а в настройках зарядного нужно включить `REMOTE_CONTROL = 1` совместно с `LOGGER`
Для одного просмотра показаний этот провод не нужен

<Callout type="warning">
  При прошивке Arduino или ESP через USB нужно отключить провод данных от логгера. Иначе устройство не прошьётся или уйдёт в бесконечный ребут.
</Callout>

Если подключён провод управления, на время прошивки его также нужно отключить

## Светодиодная индикация

Не на всех платах есть встроенный светодиод, и не каждый вариант прошивки поддерживает его работу
В поддерживаемых вариантах Logi к D4 можно подключить внешний светодиод, например для установки на корпус
Он повторяет сигналы встроенного светодиода

### Подключение внешнего светодиода

```text
3V3 (3,3 В) → резистор → анод (+) светодиода
Катод (−) светодиода → D4
```

Резистор ограничивает ток светодиода
У нового светодиода анод обычно имеет длинную ножку, катод – короткую
Со стороны катода на корпусе обычно есть плоская грань

| Плата | Вывод внешнего светодиода в Logi |
|-------|--------------------------------|
| WeMos D1 mini (ESP8266) | D4 = GPIO2. Это тот же вывод, к которому подключён встроенный светодиод |
| WeMos D1 mini32 (ESP32) | D4 = GPIO16. Прошивка повторяет на нём сигналы встроенного светодиода, подключённого к GPIO2 |

<Callout type="info">
  Обозначение D4 не одинаково у всех плат
  Перед подключением проверьте распиновку платы и поддержку светодиода в выбранной прошивке
  В готовом варианте Logi для ESP32-S3 светодиодная индикация не поддерживается
  В вариантах для ESP32-WROVER и LOLIN S2 Mini отдельный выход внешнего светодиода не используется
</Callout>
